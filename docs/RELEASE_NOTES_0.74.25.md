# Cerebra 0.74.25

Company pitches, made more reliable:

- **Application pages:** blog posts, guides, e-books, webinars, case studies and news are no longer listed as a company's application pages. Only pages for vendors, partners, linguists, contributors and careers are listed.
- **No double sends:** if Gmail sends a pitch but can't confirm its message ID, the pitch is still recorded as sent, so it never goes out twice.
- **Replies:** replies are found even when your Gmail address wasn't saved, and one deleted thread no longer stops the others being read.
- **Follow-ups:** follow-ups go out only while Company pitches is switched on and set to send by itself. None go to an address that said no thanks or bounced.
- **Better addresses:** procurement@ is used; short role words such as hi@ and hr@ never match a person's own address; data-protection inboxes are skipped.
- **Says why nothing went out:** when a scheduled run can't send (for example, Gmail needs connecting again), the page shows the reason and you get one notification, instead of only "Sent 0".
