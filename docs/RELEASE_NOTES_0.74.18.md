# Cerebra 0.74.18

Prospects now switches subscriptions by itself. If ChatGPT or Claude reaches its usage limit or times out while writing, the other one writes the draft, as long as it is signed in with a real subscription. An API key is never used. Problems now read as one plain sentence instead of log lines.

Draft emails now go to the business itself. Addresses belonging to whoever built the website, a software vendor or a parent company are passed over, sample addresses are refused and broken ones are repaired. Drafts already waiting are checked too, and the activity log tells you about any address that was taken off. You can still type any address yourself.
