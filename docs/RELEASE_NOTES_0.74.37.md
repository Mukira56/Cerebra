# Cerebra 0.74.37

- **Project priorities.** In **All projects at a glance**, give each project high, normal or low priority. When tasks from several projects are queued, high-priority projects' tasks start first, oldest first within a priority.
- **The Prompt Architect points at the right files.** Its spec names the project files whose names match your request, so Claude starts in the right place. Cerebra reads only file names for this, never their contents, and leaves out hidden folders, dependency folders and anything that may hold a secret.
- **Warnings when a model gets worse.** Model intelligence warns when a model's share of usable answers in a kind of work this week is 20 points or more below its own previous four weeks, and says what to do.
- **A check set you can run.** Model intelligence › **Run the check set** asks each kind of work a few short questions with known answers and scores them by Cerebra's own rules, not another model's opinion. Each score is shown next to the previous one, so after changing a model you can see whether the new one does better. It runs only when you press the button.
