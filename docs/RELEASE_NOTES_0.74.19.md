# Cerebra 0.74.19

Sign-in windows work again in the desktop app. The window Cerebra opens to sign in to GitHub, ChatGPT or Claude, or to install a tool, could appear blank and ignore the keyboard. It now shows its code and accepts input, and the GitHub page updates by itself once you've signed in. A GitHub CLI installed while Cerebra is running is found right away.

Settings > About you has a Clear my details button. Your details are kept when you reinstall, so that an update never loses them.

Automatic outreach now does its own research on every run. While it's on, it looks up a few business emails and websites each time, so businesses the map lists without a website get found without any other job being switched on.

Updates are more dependable. GitHub limits update checks per internet address, and that address can be shared with many other people. When the limit is reached, Cerebra now checks GitHub's web pages instead, so an update is still found. Every download is still checked against its checksum.
