# Cerebra 0.74.14

Prospects now protects your Gmail. Before an email is written or sent, Cerebra checks that the business's domain can receive mail, and skips the ones that can't. If 3 of your last 100 emails bounce, automatic sending and follow-ups pause and you're told why. Replies are still read, drafts are still written and you can still send by hand. Press Resume on the Prospects page when you've checked the addresses.

Books now gives every KDP listing a keyword score out of 100, with the search words your boxes add beyond the title. It names any box that is a single word, repeats the title or duplicates another box, and separates things you must fix from advice. Topics like "gluten free" are no longer mistaken for a price claim.

The domain check sends only the business's domain name to a public DNS service. If the lookup fails, sending goes on as normal.
