# Cerebra 0.74.32

**A redesigned interface**
- **Sharper, more precise look:** rectangular buttons, fields, tabs and panels with small corners and thin borders, compact menus and aligned spacing. The rounded pill shapes, glows and gradients are gone.
- **Colours with a meaning:**
  - indigo for Cerebra's main actions
  - green for making money
  - amber for pitching and outreach
  - violet for building software
  - teal for what happened
  - slate for settings

  Status colours are the same everywhere: green done, amber waiting for you, red failed, blue running, grey off.
- **New fonts:** Inter for reading and JetBrains Mono for code and logs. Both are bundled with Cerebra, so nothing is downloaded while you use it.
- **New line icons** in the menu and on Home.
- **Clearer layout:**
  - figures sit side by side in one framed row
  - each page title has a thin coloured bar in its section's colour
  - Settings › How Cerebra looks has simple switches for text size, colours and the menu
- **Both themes reworked:** a charcoal-and-navy dark theme and a warm light theme. All text meets accessibility contrast.
- Everything works as before: the same pages, buttons and settings.
