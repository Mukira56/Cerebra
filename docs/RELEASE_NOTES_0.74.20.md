# Cerebra 0.74.20

Your daily number now counts the emails Cerebra writes. Before, drafts could go past it, which used more of your AI subscription than you asked for. If you want more drafts each day, raise the number under Prospects > Automatic outreach.

Outreach emails are now signed with your own name when the business name is set to the app's name. Drafts waiting to be sent are corrected too. Quotes and invoices keep your business name as it is.

A lost internet connection during automatic outreach now says so plainly, and Cerebra tries again on the next run.

Installing and updating are more dependable. Setup could stop with an error if another Python program happened to close while it was checking that Cerebra wasn't running. Opening Cerebra while another copy is closing no longer shows an error either.
