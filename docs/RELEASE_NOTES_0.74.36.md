# Cerebra 0.74.36

- **All projects at a glance.** With two or more projects, the Projects page opens with one table: approvals waiting for you, tasks working, queued, stuck, done and failed, tokens used and last activity for each project. Projects that need you come first, and a project's name opens its tasks.
- **What each task used.** A finished task's report shows how many AI runs it took and the tokens they read and wrote, as Claude and Codex reported them. For Claude it also shows what the work would cost at list prices; your subscription covers it, so nothing is charged per run. Model intelligence adds **Use per project**.
- **Repeated questions aren't asked twice.** When the same research, checking or sorting question comes up again within a day, Cerebra reuses the answer instead of spending another call from a free daily allowance. Writing, plans and code questions always get a fresh answer, and the **Test** button on the Models page always asks the model for real.
